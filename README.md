# 🌱 Smart Plant Monitoring System

## 📌 About the Project

The Smart Plant Monitoring System is an IoT-based agriculture project developed to monitor important environmental conditions and support automated farming operations.

The system uses an ESP32 microcontroller, sensors and IoT technology to collect and monitor plant/environment parameters.

## 🎯 Objectives

- Monitor environmental conditions around plants
- Measure temperature, humidity and light intensity
- Support automatic irrigation
- Improve agricultural monitoring using IoT
- Reduce manual effort in farming
- Support automated agricultural operations

## 🔧 Hardware & Technologies

- ESP32
- Temperature Sensor
- Humidity Sensor
- Light Intensity Sensor
- Soil Moisture Sensor
- Motor/Actuator Modules
- Water Pump
- IoT Connectivity
- Arduino IDE
- C/C++

## 📊 Parameters Monitored

| Parameter | Purpose |
|---|---|
| Temperature | Monitor surrounding temperature |
| Humidity | Monitor environmental humidity |
| Light Intensity | Monitor available light |
| Soil Moisture | Monitor soil water condition |

## 🚜 Agricultural Functions

The proposed system includes support for:

- 💧 Automatic Irrigation
- 🌿 Grass Cutting
- 🔥 Fire Detection
- 🚜 Ploughing
- ⛏️ Digging
- 🧪 Pesticide Spraying
- 🌱 Plant Disease Detection

## ⚙️ Working Principle

1. Sensors collect environmental and soil data.
2. ESP32 processes the sensor readings.
3. The collected data can be monitored through an IoT platform.
4. Based on the required conditions, suitable agricultural operations can be activated.
5. The system helps reduce manual monitoring and supports smart farming.

## 🌐 IoT

The ESP32 provides connectivity between the agricultural monitoring system and the IoT platform, allowing sensor information to be monitored remotely.
